# Hyglac

**A computational framework to inform interpretation of hydrological processes in glacier environments through simulated seismic signals.**

Hyglac ([`hyglac.py`](hyglac.py)) simulates the seismic signals generated when moving water interacts with ice, as described in Turner et al. (2026). The modular framework has three key stages:

1. **Hydrodynamic simulation:** smoothed particle hydrodynamics (SPH) simulation of water flowing through an ice channel, using [PySPH](https://github.com/pypr/pysph).
2. **Seismic force vectors:** post-processing of the SPH output to find the water–ice interface, recover the smoothed dynamic pressure acting on it, and convert this into a time series of force vectors.
3. **Seismic wave propagation:** synthetic three-component seismograms for those forces in a layered ice and bedrock model, using [pyprop8](https://github.com/valentineap/pyprop8).

These three stages are modular. Each stage reads only the preceding stage's output, allowing different seismometer positions or Earth models to be explored without repeating the expensive hydrodynamic simulation. The framework can also extract seismic force vectors from SPH simulations run using alternative packages, while the resulting force histories can be used with other seismic wave propagation models.

**Scope.** Hyglac simulates seismic signals generated by fluid impacts, wave breaking, sloshing and large-scale turbulent structures in glacier channels. These processes generally produce lower-amplitude seismic signals than sediment transport or conduit resonance. The framework treats ice as rigid and stationary and uses an artificially reduced sound speed in water, excluding elastic ice deformation, acoustic wave propagation and conduit resonance. The spatial resolution of the SPH simulations limits the model to capturing relatively large turbulent structures.

## Installation

Hyglac is a single module, not an installable package. The required dependencies are specified in `environment.yml`. The Conda environment can be created using:

```bash
conda env create -f environment.yml
conda activate hyglac
```
Python or Jupyter can then be run from the Hyglac directory, with Hyglac imported as:

```python
import hyglac as ss
```

Both PySPH and pyprop8 must be installed to import Hyglac, even when only one stage is used.

## Quick start

The [`seismicsph_testcase.ipynb`](verification_test/seismicsph_testcase.ipynb) notebook runs the complete Hyglac workflow at low cost to check that the code works. The geometry functions `set_fluid` and `set_obstacle` are defined in the notebook. The test parameters minimise runtime and output size so that reference outputs can be included in [`verification_test/`](verification_test/) for comparison. They are not physically realistic, and the outputs should not be interpreted as scientific predictions.

```python
import numpy as np
import hyglac as ss

# 1. Hydrodynamic simulation: dam break in a 3 m x 0.2 m x 1 m tank, 1.5 s, outputs at 200 Hz
ss.run_seismic_sph(3.0, 0.2, 1.0, 1.5, 1/40, 5e-5, set_fluid, set_obstacle, output_times=np.arange(0, 1.5 + 0.0025, 0.005), filename="scurve_testcase")

# 2. Seismic force vectors
ss.seismic_sph_interactions(filename="scurve_testcase", delta=0.025,
                            dx=0.05, dy=0.05, dz=0.05, xrange=[2, 4])
forces_df = ss.seismic_sph_forces_defaults(3.0, 0.0, 500.0, filename="scurve_testcase")

# 3. Seismic wave propagation: 500 m of ice over bedrock, seismometer 1 km away at 0.5 m depth
model = ss.earth_model([(0, 3600, 1800, 916), (500, 6000, 3500, 2700)])
seismogram_df = ss.seismic_sph_signals(0, 1000, 0.5, earth_model=model, forces_df=forces_df, duration=5.001, sampling_rate=100.0)
```

| Stage | Function | Output |
| --- | --- | --- |
| Hydrodynamic simulation | `run_seismic_sph` | PySPH snapshots in `<name>_output/` |
| Interface forces | `seismic_sph_interactions` | `<name>_interactions.hdf5` |
| Seismic force vectors | `seismic_sph_forces`, `seismic_sph_forces_defaults` | Force-history DataFrame |
| Earth model | `earth_model` | `pyprop8.LayeredStructureModel` |
| Seismic wave propagation | `seismic_sph_signals` | Displacement and velocity DataFrame |
